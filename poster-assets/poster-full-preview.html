INTRODUCTION ✍️ WRITE

Dvault is a decentralized, Web3-powered cloud document vault that eliminates centralized points of failure, vendor lock-in, and unauthorized tampering prevalent in traditional cloud platforms (e.g., Google Drive, AWS S3). Storing large files directly on Ethereum smart contracts is prohibitively expensive. Dvault addresses this by combining off-chain peer-to-peer storage (IPFS) with on-chain cryptographic state verification (Solidity).

PROPOSED WORK & ARCHITECTURE

A hybrid decentralized architecture where user files are securely pinned to IPFS via Pinata, producing a unique Content Identifier (CID). The CID, file name, timestamp, and owner address are immutably anchored on-chain using Solidity. Dynamic role-based permissions (AccessControl.sol) enable users to grant or revoke third-party viewing access seamlessly without gas-heavy file duplication.

CONCLUSION

Dvault successfully demonstrates a cost-effective, tamper-proof cloud storage model by decoupling large-file off-chain storage from on-chain trust validation. It guarantees 100% data integrity, user sovereignty, and verifiable decentralized access control.
